# Départ pour Montréal

Checklist privée de préparation d'un déménagement au Québec.

Ce dépôt ne contient que l'application (affichage, connexion Google, hors connexion).
Le contenu et l'avancement sont stockés dans Firebase et ne sont lisibles que par les
comptes Google autorisés par le propriétaire. Sans accès, la page n'affiche qu'un écran
de connexion et envoie une demande d'accès.

- `index.html` : la page
- `app.js` : la logique (rendu, accès, écritures)
- `sw.js` : copie hors connexion de la page
